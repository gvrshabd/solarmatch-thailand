# SolarMatch Design v2 handoff

Copy this folder into the repository as `docs/design-v2/`.

- `DESIGN_SPEC.md`: what to build, page by page, with file paths, data fixes and rules.
- `CODEX_PROMPTS.md`: eight prompts to give ChatGPT / Codex in order.
- `tokens.css`: colour, shape, type and motion tokens.
- `prototype/`: the clickable reference. Serve it with `npx serve docs/design-v2/prototype` and open `#home`, `#estimate`, `#results`, `#installers`, `#portal`.
  - `engine.min.js` is the repository's own calculator (`lib/calculator` + `config/assessment`) bundled with esbuild, so every figure in the prototype is real.
  - Photos are Pexels (free commercial licence): Robert So, Kindel Media, Los Muertos Crew, Budget Bizar.

Thai copy is a draft for native review.

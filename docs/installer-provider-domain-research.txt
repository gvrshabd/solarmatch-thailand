Current Thai SMS requirements and test limits
Twilio's Thailand guideline requires registered sender IDs and registration of
full-length URLs with the sender; shortened URLs cannot be allowlisted. Obtain
provider approval for SolarMatch's exact purpose, Thai text and any URL before
handset tests. Do not infer permission from an API accepted/queued response.
Current new-console trials restrict SMS to the registration country and verified
recipients, expire after30days, and use predefined SMS templates rather than
arbitrary custom message bodies. Legacy trial behavior may differ; verify the
actual account, country and allowance. New-console users cannot create legacy
test credentials; old test credentials simulate API calls without handset delivery.

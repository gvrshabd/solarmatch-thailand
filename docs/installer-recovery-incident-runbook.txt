Pause / incident procedure
Use the existing authenticated, CSRF-protected installer settings controls to set
platformPaused=true, collectionEnabled=false, paymentsEnabled=false,
deliveryPaused=true, notificationsEnabled=false. Keep outbound false. Pausing
does not recall a provider call already in flight or refund a payment. Preserve
original enquiry availability/claim deadlines and financial records. Inspect job
health, due/stale queues, ambiguous provider acceptance and reconciliation errors.
Do not blindly resend ambiguous SMS or recreate an uncertain payment attempt.
Resolve evidence via the existing admin controls, not by editing ledger rows.
Capture/acknowledge local safe-code alerts; acknowledgement does not resolve them.
Verify balances, consent, recipient caps and mode isolation before resuming any
separately approved gate. Resume gates independently, never by copying demo settings.

Keep the source demo intact. A Git revert does not undo database migrations.

Real R2 procedure still requires authorised execution
Record only the SolarMatch private bucket inventory and D1 media/contract object
references. Export objects and safe metadata into access-controlled encrypted
backup, with manifest key/size/hash and timestamp; do not export credentials.
Restore to a separately approved private destination, no public ACL or overwrite
of live objects. Verify every checksum/content/custom metadata and associated D1
references before switching. Contracts belong to companies, not automatically to
purged homeowners. Honour legal holds and approved retention/backup deletion.
No automatic object deletion or claim of restoring intentionally purged PII.

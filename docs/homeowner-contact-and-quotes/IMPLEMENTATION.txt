snapshot version, not a rewritten historical scoring configuration.

is not evidence of a supplied bill. reportedBillThb is explicitly null for kWh.

the ordinary reference tariff converts mean monthly kWh into a qualification bill
equivalent. No future load, PV output, tax, export or financing benefit enters it.

monthly kWh, qualification equivalent, tariff identity/tiers/Ft/VAT/service/source
and reference date/warnings. The operational qualification event references the
normalization version/input. Existing original records are not recalculated.

value; for kWh it holds floor(calculated equivalent), never a fabricated reported
bill. The separate server snapshot identifies its meaning. Admin summaries/manual

respect assessment-field consent and withdrawal redaction. No migration or table
rebuild is needed. Future consumers of monthly_bill_thb must use the provenance
snapshot; do not assume that every modern row is a homeowner-supplied bill.

Receipts and help
A real estimate is calculated and saved before opening the contact form. Pending
submission is 'submitting', never 'submitted'. Only an API success becomes a local
'Request received' receipt; it is not proof of matching or recipient delivery.
Network/5xx uncertainty offers a retry using the same idempotency key. No lead IDs,
contact details or receipt state are added to shared estimate links. Shared links
suppress any local receipt. Policy hours/limit come from the server configuration.
Persistent status and withdrawal need separate homeowner authorization; /enquiry
remains installer staff access. No verified help email/phone is configured. See
docs/homeowner-request-access-gap.md; no fake contact channel is published.

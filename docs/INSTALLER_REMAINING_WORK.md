# Installer launch decisions and activation

This is a prelaunch local implementation. Code completion means the guarded path exists; it does not mean an account, legal term, delivery route, bank settlement or deployment has been approved. The provider gates and protected local test steps are in [provider setup](INSTALLER_PROVIDER_SETUP.md) and [local testing](installer-local-test.md). Local acceptance and the synthetic migration/restore rehearsal passed; provider/production acceptance remains separate.

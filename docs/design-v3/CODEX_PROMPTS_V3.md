First copy this folder into the repo as `docs/design-v3/`. Run the prompts in order, one per branch or session. After each one, check the changed screens at 390 px and 1440 px in English and Thai against `docs/design-v3/prototype/` and `docs/design-v3/reference/` before moving on.

Paste this preamble at the top of every prompt:

> Read `docs/design-v3/V3_SPEC.md` sections 0 and 8 first; they apply to everything. The visual reference is `docs/design-v3/prototype/` (vanilla JS; the CSS to port is the block starting `v3 · applied minimalism` at the end of `prototype/app.css`; new and changed copy is the `v3 copy` block in `prototype/app.js`). Add copy to `config/design-v2-copy.ts` in both EN and TH. Do not change calculator arithmetic, consent or legal wording, storage, API contracts or permissions unless the spec section says so. Legal text may move into a disclosure but must stay word for word. Run `pnpm lint`, `pnpm typecheck`, `pnpm test` and the Playwright suites; update selectors, never weaken assertions.
